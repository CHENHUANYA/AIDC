📡 機台整合說明
當機台發生警報，可透過 OPC-UA gateway、n8n 或任何 HTTP client 發送 POST 請求到：
POST http://YOUR_SERVER_IP:8100/trigger-alarm
頁面頂部將立即顯示紅色警報橫幅，並可一鍵查詢對應的解決方案。

# POST to this endpoint when machine alarm fires: POST http://YOUR_SERVER:8100/trigger-alarm { "alarm_code": "3000", "manual": "808d", "machine_id": "CNC-LINE-01", "source": "OPC-UA" }
